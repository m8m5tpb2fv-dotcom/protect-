# Дизайн-система «Рядом»

## Референсы и что из них взято
| Референс | Что применено |
|---|---|
| Профиль сёрф-тренера | Hero исполнителя: аватар в двойном кольце по центру, цифры по бокам, контурные кнопки-пилюли; выбор услуги радио-карточками + крупная кнопка «Заказать · цена»; имя поверх фото в карточке исполнителя |
| Workouts | Плитки категорий в форме папок с вкладкой; круглые кнопки-иконки; «живой» виджет активного заказа над навигацией |
| humbleteam (Daily memo) | Приветствие в пилюле с аватаром; двухтонный заголовок; зернистые градиентные иллюстрации; панель с выемкой-вкладкой; плавающая тёмная навигация с белым активным кругом |
| Tip calculator / Bill paid | Кнопка «Pay now» → графитовый градиент со светлой кромкой; уведомления — тёмная пилюля с кольцом-галочкой |
| Flight (YYZ → HND) | Светящийся лаймовый прогресс-бар этапов заказа |
| Recording / Dynamic Island | Крупные тонкие цифры (`.num`) в метриках |

Тёмная тема — по умолчанию (как в референсах); светлая и системная доступны в профиле.

Принцип: **UX важнее декора**. Дорого выглядит за счёт воздуха, крупной типографики и одного акцента, а не за счёт эффектов.

## Логотип
«Р-метка»: буква «Р», у которой петля — метка на карте («здесь, рядом»). Чёрный знак на лаймовой плитке.
Геометрия — единственный источник `src/lib/brand.ts`; из него собираются `LogoMark`, `public/icon.svg`, иконки PWA/iOS/Android, favicon, аватар бота и обложка Mini App (`npx tsx scripts/icons.ts`). Файлы для Telegram — `public/brand/`.

## Цвет
Токены в `src/app/globals.css` (`:root` / `[data-theme="dark"]`), Tailwind-классы генерируются из них (`bg-surface`, `text-muted`, …).

| Токен | Light | Dark | Назначение |
|---|---|---|---|
| `--bg` | `#ECECEE` нейтральный серый | `#000000` чистый чёрный | фон страницы |
| `--surface` / `--surface-grad` | `#F9F9FA` | графит `#1F1F22 → #141416` | карточки («безель» со светлой кромкой сверху) |
| `--surface-2/3` | холодные серые | графит | поля, ховеры |
| `--ink` | `#0B0B0C` | `#F5F5F4` | текст |
| `--btn` | графитовый градиент | графитовый градиент | основная кнопка |
| `--muted` | `#76767C` | `#8A8A90` | вторичный текст |
| `--accent` | `#D4F25C` «volt» | тот же | единственный акцент: главное действие, «свободен», выбранное |

Акцент используется только как **заливка с тёмным текстом** (контраст AA), никогда как цвет текста.
Семантические цвета (success/danger/warning/info) — только для статусов и всегда с текстом/иконкой.
Категории имеют пастельные «тона» (`src/lib/tones.ts`) — только для иллюстраций и плиток, не для интерфейса.

Telegram: `TelegramProvider` подменяет `--bg`, `--surface`, `--ink`, `--muted` значениями `themeParams`, акцент остаётся брендовым.

## Типографика
Inter Variable (self-hosted, кириллица). Заголовки `display` 650 / −0.038em / 0.98, `title` 620 / −0.024em. Табличные цифры для цен и метрик. Минимум 13px для вспомогательного текста, 15–17px для основного; на iOS поля ввода 16px (без зума).

## Форма
Радиусы: карточки 28px, плитки 22px, поля 18px, кнопки 16–20px / pill. Тени мягкие и длинные (`shadow-card`, `shadow-float`), бордеры — полупрозрачные линии.
Стекло (`.glass`) — только для плавающих элементов поверх контента: нижняя навигация, шапка при скролле, бейджи на фото.

## Движение
`rise` / `pop` / `sheet` с пружинной кривой `cubic-bezier(.22,1,.36,1)`, 0.3–0.5с. `press` (scale .97) на всех нажимаемых элементах, `lift` на карточках (hover только для устройств с hover). Скелетоны с shimmer. `prefers-reduced-motion` отключает анимации.

## Навигация
- Телефон/планшет/Telegram: плавающий стеклянный таб-бар (Главная · Поиск/Кабинет · **+** · Сообщения · Профиль), зона нажатия ≥ 54px, safe areas.
- Десктоп: плавающая стеклянная панель навигации сверху + двухколоночные раскладки (поиск со sticky-картой, профиль со sticky-карточкой действий, двухпанельный чат). Админка — отдельный инструмент с боковым меню и таблицами.

## Компоненты
`src/components/ui`: Button/ButtonLink, Input/Textarea/Select/Field, Switch, Segmented, Sheet (нативный `<dialog>`: bottom sheet на телефоне, модалка на десктопе), Toast, Badge/StatusDot, Avatar (монограмма в тоне), Rating/Stars, VerifiedMark, Media (без CLS), EmptyState/Skeleton/SectionHeader, Pagination, CatalogIcon.

## Доступность
Фокус-кольца, skip-link, ARIA для combobox поиска, radiogroup, role=log в чате, скрытые таблицы данных у графиков, контраст AA, alt у изображений, клавиатурная навигация в лайтбоксе.
